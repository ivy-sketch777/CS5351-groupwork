## Event 4 — Short-leave threshold fix (`<= 2` days)
Traced a failure where a 2-day medical leave request (`2026-12-08` to `2026-12-09`) missed the short-leave rule and routed to `fail_closed` because the rule threshold checked `< 2` teaching days instead of `<= 2` days.
Updated `src/policy/config/rules.yaml` to `<= 2` days and verified that `NEVER_AUTO_APPROVE` remained enforced: 2-day cases still require authorized human counselor review rather than automatic approval.

## Event 5 — Stale local SQLite schema & end-to-end API debugging

Diagnosed that a stale pre-existing `medleave.db` in the repo root lacked the newer `extraction_json` column. Stopped `uvicorn`, removed `medleave.db`, restarted the server, and verified the full 4-step API flow in PowerShell
(`pending_docs` -> `pending_docs` -> `in_review` -> `approved`) with UTF-8 output enabled.
